# Catatan rilis MIT L09

Checkpoint aditif ini harus memakai rekaman induk Zenodo `22074528`, DOI
`10.5281/zenodo.22074528`, dan konsep yang sama,
`10.5281/zenodo.22059741`. Seluruh 74 berkas induk harus diwarisi tanpa
perubahan byte. Tepat delapan tambahan checkpoint terdiri atas reader PDF dan
HTML Kuliah 5, bundel delta sumber/backend/QA yang ringkas, README ini, README
pembaca, catatan lisensi, manifest, dan checksum. PDF reader harus menjadi
pratinjau utama.

Bundel delta memuat penutup minimal yang diperlukan untuk membaca, memvalidasi,
dan melanjutkan batas halaman 50–63: sumber semantik Inggris, terjemahan
Indonesia, dukungan build, bukti QA, backend tervalidasi, sensus batas,
snapshot delapan koreksi, catatan lisensi resmi, dan kunci identitas input.
Bundel tidak memuat kontrol global yang dapat berubah, PDF otoritas, grafik
Athena, cache, render sementara, arsip bersarang, Git, atau kredensial.

Rilis tetap **belum lengkap**. Halaman 64/Kuliah 6 adalah kursor berikutnya.
Tidak ada klaim penyelesaian korpus atau dukungan oleh pihak sumber. Materi MIT
yang baru tetap tunduk pada CC BY-NC-SA 4.0, sedangkan hak berkas induk tetap
berlaku per komponen.

`release-config-mit-l09.json` sengaja tidak disediakan oleh template ini.
Generator kunci dan builder akan gagal tertutup sampai jumlah serta identitas
backend final dan hash kontrol prapublikasi disuplai dan cocok dengan byte
langsung. Berkas konfigurasi itu adalah masukan lokal dan bukan tambahan
Zenodo kesembilan.
