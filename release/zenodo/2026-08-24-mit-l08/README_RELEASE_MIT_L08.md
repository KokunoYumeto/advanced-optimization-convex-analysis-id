# Catatan rilis MIT L08

Checkpoint aditif ini memakai rekaman induk Zenodo `22074102`, DOI
`10.5281/zenodo.22074102`, dan konsep yang sama,
`10.5281/zenodo.22059741`. Seluruh 66 berkas induk harus diwarisi tanpa
perubahan byte. Delapan tambahan checkpoint terdiri atas reader PDF dan HTML
Kuliah 4, bundel delta sumber/backend/QA yang ringkas, README ini, README
pembaca, catatan lisensi, manifest, dan checksum. PDF reader harus menjadi
pratinjau utama.

Bundel delta memuat penutup minimal yang diperlukan untuk membaca, memvalidasi,
dan melanjutkan batas halaman 39–49: sumber semantik Inggris, terjemahan
Indonesia, dukungan build, bukti QA, backend tervalidasi 1.957 rekaman, sensus batas,
snapshot tiga koreksi, catatan lisensi resmi, dan kunci identitas input. Bundel
tidak memuat kontrol global yang dapat berubah, PDF otoritas, grafik Athena,
cache, render sementara, arsip bersarang, Git, atau kredensial.

Rilis tetap **belum lengkap**. Halaman 50/Kuliah 5 adalah kursor berikutnya.
Tidak ada klaim penyelesaian korpus atau dukungan oleh pihak sumber. Materi MIT
yang baru tetap tunduk pada CC BY-NC-SA 4.0, sedangkan hak berkas induk tetap
berlaku per komponen.
