# Catatan rilis MIT L06

Checkpoint aditif ini memakai rekaman induk Zenodo `22072071` dan konsep yang
sama, `10.5281/zenodo.22059741`. Lima puluh berkas induk harus diwarisi tanpa
perubahan byte. Tambahan checkpoint terdiri atas reader PDF dan HTML Kuliah 2,
bundel sumber/backend/kontrol yang ringkas, README ini, README pembaca, catatan
lisensi, manifest, dan checksum.

Bundel delta hanya memuat penutup yang diperlukan untuk melanjutkan pekerjaan:
sumber semantik Inggris, terjemahan Indonesia, dukungan build, skrip dan bukti
QA, backend 1.714 rekaman, kontrol final, catatan lisensi resmi, dan kunci
identitas input. Bundel mengecualikan PDF otoritas, grafik Athena, cache,
render sementara, arsip bersarang, Git, serta kredensial.

Rilis tetap **belum lengkap**. Batas yang diakui adalah halaman 20–28; halaman
29/Kuliah 3 adalah kursor berikutnya. Tidak ada klaim penyelesaian korpus atau
dukungan oleh pihak sumber.
