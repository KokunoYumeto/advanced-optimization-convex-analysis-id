# Catatan rilis MIT L07

Checkpoint aditif ini memakai rekaman induk Zenodo `22073743` dan konsep yang
sama, `10.5281/zenodo.22059741`. Seluruh 58 berkas induk harus diwarisi tanpa
perubahan byte. Delapan tambahan checkpoint terdiri atas reader PDF dan HTML
Kuliah 3, bundel delta sumber/backend/QA yang ringkas, README ini, README
pembaca, catatan lisensi, manifest, dan checksum. PDF reader harus menjadi
pratinjau utama.

Bundel delta memuat penutup minimal yang diperlukan untuk membaca, memvalidasi,
dan melanjutkan batas halaman 29–38: sumber semantik Inggris, terjemahan
Indonesia, dukungan build, bukti QA, backend 1.820 rekaman, sensus batas,
snapshot dua koreksi, catatan lisensi resmi, dan kunci identitas input. Bundel
tidak memuat kontrol global yang dapat berubah, PDF otoritas, grafik Athena,
cache, render sementara, arsip bersarang, Git, atau kredensial.
