This is an incremental preservation release, not the completed O015 corpus.
It contains the nine admitted, independently buildable Indonesian reader
units available at this boundary:

- Andreas Habring, *Lecture Notes: Convex Optimization*, Chapters 3-9;
- Christopher Griffin, *Nonlinear Programming*, Chapters 3-4, with
  contributions credited to Simon Miller and Douglas Mercer.

The nine PDFs are uploaded separately for direct reading. The source/backend
ZIP contains their editable TeX closure, required figures and bibliography
inputs, the deterministic modular JSONL/CSV backend, component-rights and
source-authority records, correction ledger, and bounded QA evidence. The
release manifest and SHA256SUMS bind the exact uploaded bytes.

This Zenodo concept lineage is maintained independently of the GitHub mirror.
Publishing this explicitly incomplete checkpoint is intentional preservation,
not a claim that the remaining Penn units or accessible reader surfaces exist.
