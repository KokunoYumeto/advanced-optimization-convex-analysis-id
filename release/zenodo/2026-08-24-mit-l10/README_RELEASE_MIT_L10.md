# Catatan rilis MIT L10

Checkpoint aditif ini memakai rekaman induk Zenodo `22076259`, DOI
`10.5281/zenodo.22076259`, dan konsep yang sama,
`10.5281/zenodo.22059741`. Seluruh 82 berkas induk harus diwarisi tanpa
perubahan byte. Tepat delapan tambahan checkpoint terdiri atas reader PDF dan
HTML Kuliah 6, bundel delta sumber/backend/QA yang ringkas, README ini, README
pembaca, catatan lisensi, manifest, dan checksum. PDF reader harus menjadi
pratinjau utama.

Bundel delta memuat penutup minimal yang diperlukan untuk membaca, memvalidasi,
dan melanjutkan batas halaman 64–85: sumber semantik Inggris, terjemahan
Indonesia, dukungan build, bukti QA ketat, backend tervalidasi, sensus batas,
snapshot sebelas koreksi, teks lisensi resmi, dan kunci identitas input. Bundel
tidak memuat kontrol global yang dapat berubah, PDF otoritas, grafik Athena,
cache, render sementara, dump provenans mentah, arsip bersarang, Git, atau
kredensial.

Rilis tetap **belum lengkap**. Halaman 86/Kuliah 7 adalah kursor berikutnya.
Tidak ada klaim penyelesaian korpus atau dukungan oleh pihak sumber. Materi MIT
yang baru tetap tunduk pada CC BY-NC-SA 4.0, sedangkan hak berkas induk tetap
berlaku per komponen.

Generator kunci dan builder gagal tertutup bila jumlah atau identitas backend
final, bukti QA, dan hash kontrol prapublikasi belum disuplai atau tidak cocok
dengan byte langsung. Konfigurasi rilis adalah masukan lokal dan bukan tambahan
Zenodo kesembilan.
